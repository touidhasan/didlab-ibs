# Drift Protocol, April 2026

Attackers took over Drift's admin key in two transactions one second apart, using pre-signed durable-nonce
transactions that Security Council members had signed weeks earlier, then listed a fake collateral token, lifted
withdrawal limits and drained about 20 vaults. Drift had migrated to a 2-of-5 multisig with no timelock on March 26.

## Facts and sources

- Date, loss, timeline from March 23, admin takeover, withdrawal limits removed: The Hacker News; BleepingComputer; Security Affairs.
- Pre-signed transactions obtained by social engineering; 2-of-5 multisig, zero timelock: Chainalysis analysis via Quiver research summary; KuCoin News (Chainthink).
- Attribution: Drift (UNC4736), via NK News and SC Media; Elliptic via Security Affairs.
