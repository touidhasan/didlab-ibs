# Kelp DAO, April 2026

The attacker poisoned the RPC nodes that LayerZero Labs' DVN read from, so the DVN attested a cross-chain message
that had never been sent. Kelp's adapter, configured to need only that one DVN, released 116,500 rsETH (about $292M).
Attribution: DPRK, TraderTraitor / UNC4899 (Mandiant and CrowdStrike via LayerZero).

## Facts and sources

- Mechanism, absence of key theft, 1-of-1 configuration, timeline, attribution: LayerZero incident report.
- Amount, time, pause, reverted follow-ups: CoinDesk; The Block.
- Responsibility dispute: The Block.
- Freeze and refill: Unlock (Kelp statement); KuCoin research.
