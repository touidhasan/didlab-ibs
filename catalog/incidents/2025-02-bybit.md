# Bybit, February 2025

The largest theft recorded: about 401,347 ETH plus staked ETH, moved from Bybit's Ethereum multisig cold wallet
during a scheduled transfer to its hot wallet. Signers used Safe{Wallet}; the attacker had injected JavaScript into
the Safe{Wallet} front end that activated only for Bybit's wallet, so signers approved a different transaction from
the one displayed.

## Facts and sources

- Date and mechanism (scheduled cold-to-hot transfer; injected JavaScript; Safe developer machine compromise): Bybit and Safe statements via BleepingComputer; Sygnia/Verichains forensics via The Block; NCC Group technical analysis.
- Developer machine compromised Feb 4 via a malicious Docker project: Safe's investigation as reported by Decrypt.
- Attribution: FBI public service announcement, Feb 26, 2025 (TraderTraitor).
- Amount: NCC Group (more than $1.4B incl. 401,347 ETH); SlowMist (nearly $1.5B).
